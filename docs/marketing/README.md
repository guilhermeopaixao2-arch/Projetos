## Como passar uma tarefa

Informe o código da etapa (por exemplo, E02), os acessos/IDs necessários e o escopo autorizado. Peça ao executor os entregáveis e testes previstos, registrando status e pendências na ficha E08. Nunca inclua senhas ou dados de clientes na documentação pública.
